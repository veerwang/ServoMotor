一、项目用途
--------------------------------------------------------------------------------

本项目是基于 Python 的 NiMotion 低压伺服电机控制系统，用于控制搭载 NiMotion
一体化伺服驱动器的多轴运动平台。系统通过 RS-485 总线以 Modbus RTU 协议与驱动器
通信，实现电机使能、回零、定位、点动、速度控制等功能。

适用硬件:
  - NiMotion PMMP4010D-485-OHEB-D04 一体化伺服电机 (Z4 轴, 17-bit 绝对编码器)
  - NiMotion LMS-C12-24050 一体化低压伺服电机 (Y2/Z3 轴)
  - XYG321-A 三轴滚珠丝杠驱动运动平台

主要功能:
  - 多轴控制: 支持 Z4、Y2、Z3 三轴切换与独立控制
  - CiA402 状态机: 标准伺服驱动器状态管理
  - 运动控制: Profile Position (PP) 定位、Profile Velocity (PV) 速度控制、点动
  - 回零: 限位开关回零 (Method 17) 和堵转回零 (Method 38)
  - 抱闸控制: Z4/Z3 轴自动抱闸管理
  - 图形界面: PyQt5 GUI，含电机控制、Modbus 调试、寄存器配置三种视图
  - 中英双语: 界面支持中文/英文切换

五、设计说明
--------------------------------------------------------------------------------

1. 系统架构 (五层分层设计)

  +-----------------------------------------------------------+
  |              应用层  (app/)                                 |
  |   PyQt5 GUI: 连接面板、轴选择、运动控制、                     |
  |   Modbus 调试、寄存器配置、状态监控                           |
  +-----------------------------------------------------------+
  |              高级 API 层  (servo_service/high_level_api/)   |
  |   ServoService: 统一接口，多轴管理，单位转换                  |
  |   AxisConfig: 轴参数配置 (编码器、行程、回零等)               |
  +-----------------------------------------------------------+
  |              电机控制层  (servo_service/motor_control/)      |
  |   Motor: 电机操作封装 (使能/回零/定位/速度/抱闸)              |
  |   StateMachine: CiA402 状态机实现                           |
  |   Registers: 寄存器地址映射表                                |
  +-----------------------------------------------------------+
  |              Modbus RTU 层  (servo_service/modbus_rtu/)     |
  |   ModbusClient: 协议层，寄存器读写                           |
  |   Frame: 帧构造与解析，CRC-16 校验                           |
  +-----------------------------------------------------------+
  |              串口通信层  (servo_service/serial_comm/)        |
  |   SerialPort: 线程安全的串口收发                              |
  |   PortScanner: 可用串口自动扫描                              |
  +-----------------------------------------------------------+

2. 通信协议

  - 物理层: RS-485 半双工，115200bps，8N1
  - 协议层: Modbus RTU (FC 0x03/0x04/0x06/0x10)
  - 拓扑: 一主多从，各轴通过从站地址区分
  - 32 位寄存器: 大端序 (高字在低地址)

3. 状态机 (CiA402)

  使能序列:
    Shutdown (0x06) -> Switch On (0x07) -> Enable Operation (0x0F)

  状态转换:
    Not Ready -> Switch On Disabled -> Ready to Switch On
    -> Switched On -> Operation Enabled

  故障处理:
    任意状态 -> Fault Reaction Active -> Fault
    Fault Reset (0x80) -> Switch On Disabled

4. 多轴管理

  - 共享单一 RS-485 总线，通过从站地址 (Slave ID) 区分各轴
  - 每轴独立配置: 编码器分辨率、丝杠导程、行程、回零方式、极性
  - 切换轴时自动初始化对应电机参数 (DI 配置、编码器参数等)
  - 轴切换前验证目标轴配置有效性

5. 单位转换

  位置:  mm = 编码器脉冲 / (编码器分辨率 / 丝杠导程)
  速度:  mm/s = user_units/s，其中 1mm = 编码器分辨率 / 丝杠导程 个脉冲
  加速度: mm/s^2 = user_units/s^2

  Z4 轴 (17-bit): 1mm = 13107.2 脉冲 (131072 / 10)
  Y2/Z3 轴:       1mm = 1000 脉冲    (10000 / 10)

6. GUI 设计

  三视图模式，通过菜单或快捷键切换:
    Ctrl+1  电机控制视图: 使能、点动、定位、回零、参数设置
    Ctrl+2  Modbus 调试视图: 寄存器手动读写、通信日志、统计
    Ctrl+3  寄存器配置视图: 分类浏览驱动器参数、批量读取、修改保存
