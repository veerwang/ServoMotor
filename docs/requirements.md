# 电机控制系统需求文档

## 1. 项目概述

### 1.1 项目名称
NiMotion 伺服电机控制系统

### 1.2 项目目标
开发一个基于 Modbus RTU 协议的伺服电机控制系统，提供图形化界面进行电机控制和协议调试。

### 1.3 技术栈
- **开发语言**: Python 3.x
- **GUI 框架**: PyQt5
- **通信协议**: Modbus RTU
- **硬件接口**: USB 转串口设备

---

## 2. 系统架构

### 2.1 分层架构

系统采用五层架构设计：

```
┌───────────────────────────────────────────────────┐
│            Layer 5: 应用层 (Application)            │
│           PyQt5 GUI / 界面显示与交互                │
├───────────────────────────────────────────────────┤
│                                                   │
│    ┌───────────────────────────────────────────┐  │
│    │    Layer 4: 高级 API 层 (High-level API)   │  │
│    │      用户友好的电机操作接口                  │  │
│    │      使能/正反转/回零/限位等                 │  │
│    ├───────────────────────────────────────────┤  │
│    │    Layer 3: 电机控制层 (Motor Control)     │  │  服务模块
│    │      底层电机控制、状态机、寄存器操作         │  │  (Service Module)
│    ├───────────────────────────────────────────┤  │
│    │    Layer 2: 协议层 (Modbus)               │  │
│    │      Modbus RTU 协议处理                  │  │
│    ├───────────────────────────────────────────┤  │
│    │    Layer 1: 通信层 (Serial)               │  │
│    │      串口通信功能                          │  │
│    └───────────────────────────────────────────┘  │
│                                                   │
└───────────────────────────────────────────────────┘
```

### 2.2 模块划分

| 层次 | 模块名称 | 职责 |
|------|----------|------|
| Layer 1 | `serial_comm` | 串口打开/关闭、数据收发、端口管理 |
| Layer 2 | `modbus_rtu` | Modbus RTU 协议封装、CRC 校验、帧解析 |
| Layer 3 | `motor_control` | 底层电机控制、状态机管理、寄存器读写 |
| Layer 4 | `high_level_api` | 高级电机操作接口、运动控制、配置管理 |
| Layer 5 | `app` | PyQt5 界面、用户交互、状态显示 |

### 2.3 服务模块封装

Layer 1-4 封装为独立的服务模块 `servo_service`，具备以下特性：

- **独立性**: 可脱离 GUI 独立运行
- **可测试性**: 支持 headless 模式测试
- **可复用性**: 便于集成到其他应用程序
- **接口清晰**: 提供统一的 API 接口

### 3.4 Layer 4: 高级 API 层

高级 API 层提供用户友好的电机操作接口，封装底层复杂操作，简化应用层调用。

#### 3.4.0 多轴支持 (XYG321-A)

系统支持 XYG321-A 三轴运动平台，默认控制 Z 轴。

- [ ] `Axis` 枚举定义 (X, Y, Z)
- [ ] `AxisConfig` 配置类（型号、功率、导程、速度、行程等）
- [ ] 预定义轴配置 `AXIS_CONFIGS`
- [ ] 按轴获取电机实例 `get_motor_by_axis(axis)`
- [ ] 获取所有轴实例 `get_all_motors()`
- [ ] 轴配置查询 `get_axis_config()`
- [ ] Z 轴抱闸控制 `release_brake()` / `engage_brake()`
- [ ] 轴参数自动限制（速度、行程范围）

**轴默认配置**:

| 轴 | 从站地址 | 型号 | 功率 | 导程 | 最大速度 | 行程 | 抱闸 |
|----|----------|------|------|------|----------|------|------|
| X | 0x01 | CFG8 | 200W | 20mm | 1000mm/s | 50~1100mm | 无 |
| Y | 0x02 | CFG5 | 100W | 10mm | 500mm/s | 100~500mm | 无 |
| Z | 0x03 | CFG4 | 100W | 10mm | 500mm/s | 0~100mm | 有 |

#### 6.3.2 多轴控制示例

```python
from servo_service import ServoService
from servo_service.high_level_api import Axis

# 创建服务实例并连接
service = ServoService()
service.connect('/dev/ttyUSB0', 115200)

# 获取所有轴
motor_x = service.get_motor_by_axis(Axis.X)  # 从站地址 1
motor_y = service.get_motor_by_axis(Axis.Y)  # 从站地址 2
motor_z = service.get_motor_by_axis(Axis.Z)  # 从站地址 3

# 或者一次性获取所有轴
motors = service.get_all_motors()  # {Axis.X: motor_x, Axis.Y: motor_y, Axis.Z: motor_z}

# 使能所有轴
for axis, motor in motors.items():
    config = motor.get_axis_config()
    print(f"使能 {axis.value} 轴 (从站 {config.slave_id})...")
    motor.enable()

# 各轴移动到指定位置 (考虑各轴行程限制)
motor_x.set_position_mode()
motor_x.move_absolute(position=500, velocity=800)  # X轴最大 1000mm/s

motor_y.set_position_mode()
motor_y.move_absolute(position=200, velocity=400)  # Y轴最大 500mm/s

motor_z.set_position_mode()
motor_z.move_absolute(position=50, velocity=300)   # Z轴最大 500mm/s

# 等待所有轴到位
for axis, motor in motors.items():
    motor.wait_for_position_reached(timeout=30.0)
    print(f"{axis.value} 轴到位")

# 读取各轴状态
for axis, motor in motors.items():
    config = motor.get_axis_config()
    pos = motor.get_current_position()
    print(f"{axis.value} 轴位置: {pos} (行程范围: {config.stroke_min}~{config.stroke_max} mm)")

# 去使能所有轴
for motor in motors.values():
    motor.disable()

service.disconnect()
```

#### 6.3.3 Z 轴抱闸控制示例

```python
from servo_service import ServoService
from servo_service.high_level_api import Axis

service = ServoService()
service.connect('/dev/ttyUSB0', 115200)

# 获取 Z 轴
motor_z = service.get_motor_by_axis(Axis.Z)

# 检查是否有抱闸
if motor_z.has_brake():
    print("Z 轴配有抱闸")

    # 使能时自动释放抱闸
    motor_z.enable()

    # 进行定位操作
    motor_z.set_position_mode()
    motor_z.move_absolute(position=80, velocity=200)
    motor_z.wait_for_position_reached()

    # 手动锁定抱闸 (不去使能)
    motor_z.engage_brake()
    print("抱闸已锁定，电机仍保持使能")

    # 手动释放抱闸
    motor_z.release_brake()
    print("抱闸已释放")

    # 去使能 (自动锁定抱闸)
    motor_z.disable()
    print("电机去使能，抱闸自动锁定")

service.disconnect()
```
