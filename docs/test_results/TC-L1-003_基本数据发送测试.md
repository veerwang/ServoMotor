## 测试用例详情

### 测试 1: 发送 Modbus 请求帧

| 项目 | 内容 |
|------|------|
| **测试步骤** | 构建读取 Z 轴状态字的 Modbus 请求帧并发送 |
| **请求帧结构** | 从站地址(03) + 功能码(03) + 寄存器地址(0381) + 数量(0001) + CRC |
| **预期结果** | 成功发送 8 字节 |
| **实际结果** | 发送 8 字节成功 |
| **测试状态** | **通过** |

**帧数据详情:**
```
请求帧 (不含CRC): 03 03 03 81 00 01
请求帧 (含CRC):   03 03 03 81 00 01 D5 84
帧长度: 8 字节

帧解析:
  [03]       - 从站地址 (Z轴 = 3)
  [03]       - 功能码 (读保持寄存器)
  [03 81]    - 寄存器地址 (0x0381 = 状态字)
  [00 01]    - 读取数量 (1 个寄存器)
  [D5 84]    - CRC-16 校验
```
