## 状态字位定义

```
状态字 0x1231 = 0001 0010 0011 0001

Bit 15-14: 保留
Bit 13:    跟随误差 (Following Error)         = 0
Bit 12:    设定点确认 (Set Point Ack)         = 1
Bit 11:    内部限位激活                        = 0
Bit 10:    目标到达 (Target Reached)          = 0
Bit 9:     远程控制 (Remote)                  = 1
Bit 8:     保留
Bit 7:     警告 (Warning)                     = 0
Bit 6:     开机禁用 (Switch On Disabled)      = 0
Bit 5:     快速停止 (Quick Stop)              = 1
Bit 4:     电压使能 (Voltage Enabled)         = 1
Bit 3:     故障 (Fault)                       = 0
Bit 2:     操作使能 (Operation Enabled)       = 0
Bit 1:     已开机 (Switched On)               = 0
Bit 0:     准备开机 (Ready To Switch On)      = 1
```
