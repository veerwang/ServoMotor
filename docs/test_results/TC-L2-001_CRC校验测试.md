## CRC-16 算法说明

### Modbus CRC-16 特点

- 多项式: 0xA001 (反转的 0x8005)
- 初始值: 0xFFFF
- 结果处理: 低字节在前，高字节在后

### 计算示例

```python
def calculate_crc(data: bytes) -> int:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 0x0001:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc
```
