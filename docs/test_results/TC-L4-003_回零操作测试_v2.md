## 问题根因分析

### 初始测试失败

第一轮测试中，所有回零方式都立即失败，报错 0x8610 (回零超时)。

### 根本原因

**回零超时参数 (2005h:1Ch = 0x012E) 被设置为 0ms**

| 参数 | 初始值 | 问题 |
|------|--------|------|
| 回零超时 | 0ms | 任何回零操作都会立即超时 |

### 修复方案

将回零超时参数设置为合理值（30000ms-60000ms），并保存到 EEPROM。

```
寄存器: 0x012E (2005h:1Ch)
修改前: 0
修改后: 60000 (60秒)
```
