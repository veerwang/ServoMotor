**Modbus 标准异常码:**

| 异常码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | Illegal Function | 不支持的功能码 |
| 0x02 | Illegal Data Address | 非法数据地址 |
| 0x03 | Illegal Data Value | 非法数据值 |
| 0x04 | Slave Device Failure | 从站设备故障 |
| 0x05 | Acknowledge | 确认 (处理中) |
| **0x06** | **Slave Device Busy** | **从站设备忙** |
| 0x07 | Negative Acknowledge | 否定确认 |
| 0x08 | Memory Parity Error | 存储器奇偶校验错误 |

## 异常处理代码示例

```python
from servo_service.modbus import ModbusRTU, ModbusException

modbus = ModbusRTU(port='/dev/ttyUSB0', baudrate=115200)
modbus.connect()

try:
    modbus.write_register(slave_id=3, address=0x0380, value=0x0006)
except ModbusException as e:
    print(f"Modbus 异常: {e}")
    print(f"功能码: 0x{e.function_code:02X}")
    print(f"异常码: 0x{e.exception_code:02X}")
    print(f"说明: {e.get_description()}")
```

输出:
```
Modbus 异常: FC=0x06, 异常码=0x06 (从站设备忙)
功能码: 0x06
异常码: 0x06
说明: 从站设备忙
```
