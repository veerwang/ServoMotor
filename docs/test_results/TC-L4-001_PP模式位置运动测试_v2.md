## 与 v1 版本的差异

### 修复的问题

1. **32位寄存器字节序错误**

   - v2: 修正为大端序 (高字在低地址)

2. **寄存器地址错误** (v1 已修复)
   - 实际位置: 0x03A7 → 0x03C8
   - 目标位置: 0x03BD → 0x03E7

## 关键发现

### 32位寄存器字节序

NiMotion 驱动器使用**大端序** (Big Endian):
- 高字 (High Word): 基础地址 (低地址)
- 低字 (Low Word): 基础地址 + 1 (高地址)

```python
# 正确的读取方式
values = read_holding_registers(slave, address, 2)
value = (values[0] << 16) | values[1]  # 大端序

# 正确的写入方式
high = (value >> 16) & 0xFFFF
low = value & 0xFFFF
write_multiple_registers(slave, address, [high, low])  # 大端序
```

### PP 模式单位

- 位置: user units (编码器脉冲)
- 速度: user units/s (不是 RPM)
- 加速度: user units/s²
