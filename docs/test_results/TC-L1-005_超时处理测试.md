## 超时机制详解

### read_until() 超时行为

```python
# read_until() 在超时时抛出 ReadTimeoutError
try:
    data = port.read_until(expected_length=7, timeout=0.5)
except ReadTimeoutError as e:
    # 超时处理
    print(f"超时: {e}")
```

### read() 超时行为

```python
# read() 在超时时返回已读取的数据 (可能为空)
data = port.read(10)  # 超时后返回 b'' 或部分数据
```

### 动态修改超时

```python
port = SerialPort(port='/dev/ttyUSB0', timeout=1.0)
port.open()

# 运行时修改超时
port.timeout = 0.2  # 立即生效
```
