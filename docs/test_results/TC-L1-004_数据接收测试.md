## 测试执行结果

### 测试 1: 发送请求并接收响应 (Z轴状态字)

| 项目 | 内容 |
|------|------|
| **发送数据** | `03 03 03 81 00 01 D5 84` |
| **接收数据** | `03 03 02 12 60 CD 0C` |
| **响应长度** | 7 字节 |
| **CRC 校验** | 通过 |
| **测试状态** | **通过** |

**响应帧解析:**
```
收到响应: 03 03 02 12 60 CD 0C

解析:
  [03]       - 从站地址 (Z轴)
  [03]       - 功能码 (读保持寄存器)
  [02]       - 字节数 (2 字节)
  [12 60]    - 数据 (状态字)
  [CD 0C]    - CRC-16 校验

状态字值: 0x1260
```

**状态字位解析 (0x1260):**
```
Bit 0  (0): Ready to switch on    = 0
Bit 1  (1): Switched on           = 0
Bit 2  (1): Operation enabled     = 0
Bit 3  (0): Fault                 = 0
Bit 4  (1): Voltage enabled       = 0
Bit 5  (1): Quick stop            = 1 (快速停止未激活)
Bit 6  (1): Switch on disabled    = 1
Bit 9  (1): Remote                = 1
Bit 12 (1): Set-point acknowledge = 1

驱动器状态: Switch On Disabled (开机禁用)
```
