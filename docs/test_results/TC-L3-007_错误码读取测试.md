## 错误码定义

| 错误码 | 含义 | 说明 |
|--------|------|------|
| 0x0000 | 无错误 | 正常状态 |
| 0x2310 | 过流 | 电流超过限制 |
| 0x2320 | 短路 | 检测到短路 |
| 0x3110 | 主电源过压 | 输入电压过高 |
| 0x3120 | 主电源欠压 | 输入电压过低 |
| 0x3210 | DC-link 过压 | 直流母线过压 |
| 0x3220 | DC-link 欠压 | 直流母线欠压 |
| 0x4210 | 驱动器过温 | 驱动器温度过高 |
| 0x4310 | 电机过温 | 电机温度过高 |
| 0x7121 | 电机堵转 | 电机堵转保护 |
| 0x7300 | 编码器错误 | 编码器通信异常 |
| 0x8611 | 位置跟随误差 | 跟随误差过大 |
| 0x8612 | 位置超限 | 超出软限位 |

## 故障复位方法

```
1. 读取状态字确认故障状态

3. 等待 100ms
4. 写入控制字 0x0080 (Bit 7 上升沿)
5. 等待 200ms
6. 读取状态字确认故障已清除
```
