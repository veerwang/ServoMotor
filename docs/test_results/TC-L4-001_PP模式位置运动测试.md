## 问题分析

### 观察到的现象

1. **通信正常**: Modbus 通信工作正常，寄存器读写响应正确
2. **状态机正常**: CiA402 状态转换正确执行
3. **命令接收正常**: SET_POINT_ACK = True，驱动器确认收到目标位置
4. **电机未运动**: 位置始终为 0，速度和转矩均为 0

### 可能的原因

1. **硬件层面**:
   - 电机主电源未上电
   - 电机与驱动器未正确连接
   - 电机刹车未释放
   - 编码器信号异常

2. **参数配置**:
   - 编码器分辨率未配置 (608Fh 返回 0/0)
   - 可能需要额外的使能信号

3. **地址映射**:
   - 部分 32 位寄存器地址可能不正确
   - 轮廓速度写入失败 (异常码 0x06)
