### 测试 1: 基本打开/关闭

| 项目 | 内容 |
|------|------|
| **测试步骤** | 1. 创建 SerialPort 实例<br>2. 检查初始状态<br>3. 调用 open()<br>4. 检查打开状态<br>5. 调用 close()<br>6. 检查关闭状态 |
| **预期结果** | 初始: False → 打开后: True → 关闭后: False |
| **实际结果** | 初始: False → 打开后: True → 关闭后: False |
| **测试状态** | **通过** |

```python
port = SerialPort(port='/dev/ttyUSB0', baudrate=115200)
# 初始状态: is_open = False
port.open()
# 打开后: is_open = True
# 串口信息: SerialPort(/dev/ttyUSB0, 115200, open)
port.close()
# 关闭后: is_open = False
```
