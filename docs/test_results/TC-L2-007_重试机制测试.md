## 重试机制详解

### 重试流程

```
┌─────────────────────────────────────────────┐
│                  发送请求                    │
└─────────────────────────────────────────────┘
                      │
                      ▼
              ┌───────────────┐
              │   等待响应    │
              └───────────────┘
                      │
          ┌───────────┴───────────┐
          │                       │
          ▼                       ▼
   ┌─────────────┐         ┌─────────────┐
   │  收到响应   │         │    超时     │
   └─────────────┘         └─────────────┘
          │                       │
          ▼                       ▼
   ┌─────────────┐         ┌─────────────┐
   │  验证 CRC   │         │ 重试计数+1  │
   └─────────────┘         └─────────────┘
          │                       │
          ▼               ┌───────┴───────┐
   ┌─────────────┐        │               │
   │    成功     │        ▼               ▼
   └─────────────┘   < 最大次数?      = 最大次数
                          │               │
                          ▼               ▼
                    ┌───────────┐   ┌───────────┐
                    │  重新发送  │   │ 抛出异常  │
                    └───────────┘   └───────────┘
```

### 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| retries | 3 | 最大重试次数 |
| timeout | 0.5s | 单次超时时间 |
| retry_delay | 0.1s | 重试间隔 |

## 代码示例

```python
from servo_service.modbus import ModbusRTU

# 配置重试参数
modbus = ModbusRTU(
    port='/dev/ttyUSB0',
    baudrate=115200,
    timeout=0.5,
    retries=3
)
modbus.connect()

try:
    # 请求不存在的从站
    result = modbus.read_holding_registers(
        slave_id=0xFF,
        address=0x0381,
        count=1
    )
except TimeoutError as e:
    print(f"通信超时: {e}")
    # 已重试 3 次，全部超时
```
