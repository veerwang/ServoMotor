## 测试目的

验证系统能够正确扫描并列出所有可用的串口设备，特别是 USB-RS485 转换器。

---

## 测试步骤

1. 导入 `PortScanner` 类
2. 创建扫描器实例
3. 执行 `scan_ports()` 方法
4. 检查返回的串口列表
5. 验证目标串口 (USB-RS485) 是否在列表中

---

## 测试代码

```python
from servo_service.serial_comm import PortScanner

scanner = PortScanner()
ports = scanner.scan_ports()

print(f"发现 {len(ports)} 个串口:")
for port in ports:
    print(f"  设备: {port.device}")
    print(f"  描述: {port.description}")
    print(f"  硬件ID: {port.hwid}")
```

## 测试结果

### 执行状态: 通过

### 发现串口数量: 33

### 关键串口信息

| 设备 | 描述 | 硬件 ID | 类型 |
|------|------|---------|------|
| `/dev/ttyUSB0` | FT232R USB UART | USB VID:PID=0403:6001 SER=A10PGAE3 LOCATION=1-5.4 | USB-RS485 转换器 |
| `/dev/ttyS0` - `/dev/ttyS31` | n/a | n/a | 虚拟串口 |

### 目标设备详情

```
设备:    /dev/ttyUSB0
描述:    FT232R USB UART - FT232R USB UART
硬件ID:  USB VID:PID=0403:6001 SER=A10PGAE3 LOCATION=1-5.4
```

**设备识别:**
- 芯片型号: FTDI FT232R
- USB Vendor ID: 0403 (Future Technology Devices International)
- USB Product ID: 6001 (FT232 USB-Serial)
- 序列号: A10PGAE3
- USB 位置: 1-5.4

2. 成功检测到 1 个 USB 串口设备 (`/dev/ttyUSB0`)，这是实际连接的 USB-RS485 转换器
3. USB 设备使用 FTDI FT232R 芯片，这是常见的 USB 转串口芯片，兼容性良好
