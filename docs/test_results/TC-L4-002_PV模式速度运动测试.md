## PV 模式单位说明

| 参数 | 寄存器 | 单位 |
|------|--------|------|
| 目标速度 | 60FFh (0x0448) | user units/s |
| 实际速度 | 606Ch (0x03D5) | RPM |
| 轮廓加速度 | 6083h (0x03FC) | user units/s² |
| 轮廓减速度 | 6084h (0x03FE) | user units/s² |

**单位换算** (encoder_resolution = 10000):
```
RPM = target_velocity × 60 / encoder_resolution
例如: 50000 user units/s = 50000 × 60 / 10000 = 300 RPM
```
