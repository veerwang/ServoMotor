## 4. 关键技术发现

### 4.1 32位寄存器字节序

NiMotion 驱动器使用 **大端序 (Big Endian)**:
- 基础地址: 高字 (High Word)
- 基础地址+1: 低字 (Low Word)

```python
# 正确读取方式
high = read_register(addr)
low = read_register(addr + 1)
value = (high << 16) | low
```

### 4.2 单位换算

| 参数 | 值 | 说明 |
|------|-----|------|
| 编码器分辨率 | 10000 pulses/rev | 608Fh |
| 齿轮比 | 1:1 | 6091h |
| 丝杆导程 | 10mm | 1圈=10mm |
| **换算系数** | **1000 units = 1mm** | 已验证 |

### 4.3 限位开关配置

| DI | 功能 | 逻辑 | 说明 |
|----|------|------|------|
| DI2 | 15 (负限位) | 0 (Active Low) | LED亮=未触发 |
| DI3 | 14 (正限位) | 0 (Active Low) | LED亮=未触发 |

**60FDh 状态位**:
- Bit0: 负限位触发
- Bit1: 正限位触发
- Bit2: 原点开关触发

## 5. 已知问题

### 5.1 CiA402 HM模式超时

**问题**: 内置回零模式 (6098h) 总是返回超时错误 0x8610

**原因分析**:
- 默认回零超时参数 (2005h:1Ch) 可能为0
- 即使设置超时值，仍然立即失败

**解决方案**: 使用手动回零方式 (PV模式 + 限位检测)
