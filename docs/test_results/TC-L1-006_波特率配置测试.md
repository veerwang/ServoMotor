## 波特率配置方法

### 构造函数配置

```python
port = SerialPort(port='/dev/ttyUSB0', baudrate=115200)
```

### 动态修改 - set_baudrate()

```python
port.set_baudrate(115200)
```

### 动态修改 - configure()

```python
port.configure(
    baudrate=115200,
    timeout=0.5,
    bytesize=8,
    parity='N',
    stopbits=1
)
```
