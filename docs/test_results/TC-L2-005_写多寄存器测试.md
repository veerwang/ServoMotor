## FC=0x10 帧格式

### 请求帧格式

| 字段 | 长度 | 说明 |
|------|------|------|
| 从站地址 | 1 字节 | |
| 功能码 | 1 字节 | 0x10 |
| 起始地址 | 2 字节 | 高位在前 |
| 寄存器数量 | 2 字节 | 高位在前 |
| 字节数 | 1 字节 | = 寄存器数量 × 2 |
| 寄存器值 | N 字节 | 高位在前 |
| CRC | 2 字节 | 低位在前 |

### 响应帧格式

| 字段 | 长度 | 说明 |
|------|------|------|
| 从站地址 | 1 字节 | 回显 |
| 功能码 | 1 字节 | 0x10 |
| 起始地址 | 2 字节 | 回显 |
| 寄存器数量 | 2 字节 | 回显 |
| CRC | 2 字节 | |

## 与 FC=0x06 对比

| 特性 | FC=0x06 | FC=0x10 |
|------|---------|---------|
| 驱动器支持 | 受限 (返回设备忙) | 完全支持 |
| 单寄存器写入 | 设计用途 | 可用 |
| 多寄存器写入 | 不支持 | 支持 |
| 请求帧长度 | 8 字节 | 9+ 字节 |
| **推荐使用** | 否 | **是** |

**测试结果: 通过 (2/2)**

写多寄存器功能 (FC=0x10) 工作正常：

4. **CRC 验证**: CRC 校验通过
