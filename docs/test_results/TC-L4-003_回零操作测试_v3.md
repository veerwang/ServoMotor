## 问题发现与修复

### 初始问题

限位开关回零测试失败，报告 Homing Error (状态字 0x2228)

### 根因分析

通过诊断发现 **限位开关接线与软件配置不匹配**：

| DI | 软件配置 | 物理接线 | 问题 |
|----|----------|----------|------|
| DI2 | 正限位(14) | 实际接负限位 | 接反 |
| DI3 | 负限位(15) | 实际接正限位 | 接反 |

**诊断证据**:
- 电机位置在机械最低点（上次堵转回零后的位置）
- DI2 显示低电平触发
- 如果 DI2 真的是正限位，电机应该在最高点，矛盾

### 修复方案

交换 DI2 和 DI3 的功能配置（软件修复）：

```
修改前:
  DI2: 功能=14 (正限位)
  DI3: 功能=15 (负限位)

修改后:
  DI2: 功能=15 (负限位)
  DI3: 功能=14 (正限位)
```

修改后限位状态正确：
- DI2 (负限位) 触发 → 电机在最低位置 ✓

## 技术备注

### 60FDh 寄存器映射问题

在测试过程中发现 CiA402 数字输入寄存器 (60FDh) 的低位始终为 0，没有正确映射限位信号：

```
60FDh 读取值: 0x002E0000 / 0x002D0000
  低 16 位: 0x0000 (限位信号应在这里)
```

但是驱动器内部能通过 DI 功能配置 (2003h 组) 正确识别限位信号，回零操作正常完成。

如需通过 60FDh 监控限位状态，可能需要额外的映射配置。当前推荐使用物理 DI 监控寄存器 (200Bh:05h = 0x01E2) 来读取限位状态。

### 限位开关类型

当前配置假设限位开关为 **NO (常开) 型**，低电平有效：
- 未触发: 开关断开 → DI 高电平
- 触发: 开关闭合 → DI 低电平
